Entry for the [make.fun bounty "One Line, No Deadline Met"](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce) — a single-line joke giving an excuse for a missed deadline, capped at 200 characters.

## The line

> I uploaded it at 11:58, the office Wi-Fi cut out at 99%, and by the time it reconnected the timestamp had already written my excuse for me in a font I can't argue with.

168 characters, one sentence, punch at the end.

## How it runs

`main.py` (Python standard library only) writes that one line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default):

```sh
python3 main.py
```

## Why this angle

The field converged on personifying the deadline ("stood me up", "ghosted me").
This entry takes a fresher angle instead: a specific moment (11:58), concrete
artifacts (the Wi-Fi dying at 99%, the file timestamp), and a turn at the end —
the timestamp is the one that writes the excuse. It reads like something a
person would actually say when cornered.
